How the calculation or recommendation works

The generator adds protected data to a changed-data reserve calculated as data times change rate times months times 0.55. It assigns the reserve to an independent local copy and the requested offsite component. The 3-2-1 Backup Plan Generator keeps copy topology arithmetic transparent, allowing the 3-2-1 starting plan to be checked without a vendor account. In 3-2-1 Backup Plan Generator, follow every data, change, and copy roles unit shown by 3-2-1 Backup Plan Generator. Decimal TB and TiB answer capacity questions. Keep every 3-2-1 Backup Plan Generator input in its displayed unit; preserve those 3-2-1 Backup Plan Generator labels when sharing or checking the result. Round the 3-2-1 starting plan upward only after reviewing the unrounded 3-2-1 Backup Plan Generator result.

Worked example

For 4 TB, 5% monthly change, and twelve months, the modeled changed reserve is 1.32 TB. A local destination therefore needs about 5.32 TB before separate offsite capacity and provider-specific overhead. Assumptions and limitations

The 0.55 factor is a transparent planning simplification, not a promise about compression or deduplication. The page does not judge media diversity, account compromise, immutability, legal retention, or service durability. The 3-2-1 Backup Plan Generator is a planning aid for data, change, and copy roles in 3-2-1 Backup Plan Generator. Treat the copy topology assumptions as boundaries: the 3-2-1 starting plan supports copy topology planning only. It does not certify an implementation of 3-2-1 Backup Plan Generator, guarantee recovery, or provide financial advice.
