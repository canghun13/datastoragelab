What this calculator assumes

All drives have the same decimal-TB capacity. A mirror uses one drive’s capacity; single parity uses one drive’s capacity; dual parity uses two. The operating system may show a smaller binary TiB value.

What it does not decide

Capacity math does not select the right protection policy. Use the RAID Protection Decision Tool and retain independent backup copies.

How the calculation or recommendation works

Raw capacity is drive count multiplied by drive size. Usable TB subtracts one drive-equivalent for single parity, two for dual parity, or half the drives for a mirror; displayed TiB converts decimal bytes to binary units. The RAID Capacity Calculator keeps RAID arithmetic arithmetic transparent, allowing the raw-to-usable comparison to be checked without a vendor account. In RAID Capacity Calculator, follow every drive count and layout unit shown by RAID Capacity Calculator. Decimal TB and TiB answer capacity questions.
