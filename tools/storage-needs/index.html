Planning path

How to use the Storage needs hub

Where to start

Start with the decision that has the least reliable evidence. A household with several devices should begin with the Home Storage & Backup Planner; a known capacity with uncertain growth belongs in Annual Storage Growth Calculator. Creator Media separates fast working space, archive, and copies, while Computer Backup focuses on retained versions. Small Office adds users and network context, and Media Library uses linear annual additions.

Recommended workflow

Use a measured current-data total first, model growth second, and add independent copies third. Carry the resulting usable-capacity target into NAS configuration instead of treating raw drive labels as usable space. If upload or restore timing affects the design, continue to network performance before pricing. This order keeps capacity, protection, recovery, and transfer constraints distinct while allowing each later tool to reuse the earlier evidence.

What to prepare

Prepare folder or device used-space reports, a one-year history if available, the planning horizon, expected additions or percentage growth, retention needs, and the number of truly independent copies. Separate replaceable downloads from irreplaceable originals. Record whether inputs are GB, decimal TB, or TiB, and note the date measured; stale inventory is often a larger error than rounding.

What to do next

After capacity is credible, open the NAS Bay, Drive Count & Capacity Planner for a physical layout, the 3-2-1 Backup Plan Generator for copy topology, and the Full Storage System Budget Planner for complete acquisition and operating cost. Revisit this cluster annually or after a new camera, employee, computer, project type, or retention policy materially changes the data stream.
