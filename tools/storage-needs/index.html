Capacity is usable, not raw

A label capacity on a drive does not equal protected usable capacity. The planner labels decimal TB and accounts for a protection approach.

Backup is a separate decision

Local copies and offsite recovery capacity are estimated separately so a protected array is not mistaken for a backup plan.

Before you start

Bring estimates, not perfect measurements.

Use the amount of data you actively keep, an honest growth rate, the length of time you want the configuration to last, and an estimate of what must be recoverable. You can revise each assumption after seeing the result.

The recommendation is a planning aid. It does not substitute for a manufacturer’s supported RAID documentation, an electrical runtime chart, or professional advice for business-critical systems.
