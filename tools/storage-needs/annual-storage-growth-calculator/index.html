How to act on this result

Compare this usable target with a protected array, not raw drive labels. Use the TB vs TiB reference before comparing operating-system displays.

When this calculator is useful

Use it before buying a larger drive, selecting a NAS capacity, or deciding whether an existing backup target has enough runway. It models capacity, not protection: array overhead and independent copies are separate decisions.

Method and limits

Percentage growth compounds each year. Fixed annual additions are useful when an archive receives a predictable amount of material. Results are planning estimates; compression, deletion, and vendor-specific array behavior can alter actual space use.
