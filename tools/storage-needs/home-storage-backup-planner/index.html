    How this recommendation works

    Assumptions you can inspect and adjust

    The planner grows your current decimal-TB data by the annual rate over the selected period, adds expansion headroom, then tests a same-size drive layout with the protection level you selected. Backup capacity is estimated separately from the important-data share, retention level, local copies, and optional offsite copy.

    Transfer time assumes 75% of the entered upload speed. Cost is a broad planning range based on capacity class and equipment categories, not a live product quote. Mixed drive sizes, vendor-specific RAID behavior, data compression, and actual UPS runtime need separate confirmation before purchase.

    How to use the result

    1. Adjust any assumption that feels optimistic or unclear.
    2. Use the configuration as a specification brief: bays, drive count, minimum drive size, protection, backup capacity, network tier, and UPS class.
    3. Confirm compatible layouts, drive recording method, power/runtime figures, and software support with the vendors you evaluate.
    4. Set a reminder to revisit the plan before available usable capacity falls below 20%.
