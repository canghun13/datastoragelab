How to use the Reference library hub

Where to start

Use references when a number, unit, or workflow state needs independent checking. TB vs TiB explains capacity displays. RAID formulas separate raw and usable space. Transfer equations connect bytes to practical duration. UPS definitions distinguish watts, VA, and runtime. The field media checklist records the evidence required before source cards move from exposed to released.

Recommended workflow

Open the relevant reference beside the calculator, reproduce one result manually, and confirm units before changing assumptions. For field copies, compare the checklist with the application's report and every physical device label. Trace the source batch to each destination and its verification status. Keep arithmetic verification distinct from deciding acceptable operational risk or authorizing a card format.

What to prepare

Collect the original value with its unit, calculator inputs, and any rounding or efficiency assumption. A field handoff also needs source identifiers, destination roles, copy times, verification method, exceptions, manifest path, custody, and release authority. Vendor-specific reserves, runtime curves, supported media, and application behavior remain authoritative for exact equipment; these pages provide generic definitions and audit structure.

What to do next

Return to the matching tool after checking the formula or record, save corrected inputs, and explain any remaining difference. Use Guides when the math is clear but the decision tradeoff is not, and Comparisons when approaches need equal-criteria evaluation. Report a suspected defect through the contact page with the URL, inputs, expected result, and reproducible steps.
