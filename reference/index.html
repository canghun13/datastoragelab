How to use the Reference library hub

Where to start

Use references when a number or unit needs independent checking. TB vs TiB explains why drive labels and operating systems differ. Storage and RAID Capacity Formulas separates raw, usable, protection overhead, and binary display. Backup Transfer Time and Bandwidth provides the TB-to-Mbps timing equation. UPS Watts, VA, and Runtime separates real power, apparent power, and battery duration.

Recommended workflow

Open the reference beside the calculator, reproduce one result manually, and confirm units before changing assumptions. Trace capacity from decimal bytes through protection overhead and TiB display; trace transfer from TB through megabits and effective Mbps; trace UPS from measured watts through headroom, power factor, and manufacturer runtime curves. Keep formula verification separate from deciding acceptable risk.

What to prepare

Collect the original value with its unit, the calculator inputs, and any rounding or efficiency assumption. Avoid copying a number without TB, TiB, GB, Mbps, MB/s, W, VA, Wh, hours, or currency context. Vendor-specific reserves and runtime curves remain authoritative for exact equipment, while these pages provide transparent generic arithmetic and interpretation boundaries.

What to do next

Return to the matching tool after checking the formula, save the corrected inputs, and explain any remaining difference. Use Guides when the math is clear but the decision tradeoff is not, and Comparisons when two approaches need equal-criteria evaluation. Report a suspected formula defect through the contact page with the page URL, inputs, expected result, and calculation steps.
