3-2-1 Backup Explained

Use the principle as a recovery checklist: independent copies, different failure domains, and a tested path back.

The principle

Keep multiple copies, on more than one kind of storage or failure domain, with one copy offsite or otherwise separated. The goal is recoverability, not a ritual count.

Apply it

Start with production data, add a separate local target for speed, add an offsite component for site risk, and test a restore.
