How to use the Guides hub

Where to start

Start with the guide that explains the assumption blocking your decision. Capacity, RAID, backup retention, snapshots, media, replacement, UPS, SSD endurance, and field offload guides each connect a concept to an available calculator. The field workflow explains why card capacity, destination copies, verification evidence, and permission to format belong to distinct operational states.

Recommended workflow

Read one concept guide, return to the matching calculator with better evidence, and save the revised result. Capacity normally precedes configuration, configuration precedes backup topology, and recovery requirements precede network and cost. For capture media, estimate cards, benchmark copying, allocate separate destinations, then set the release rule. Follow internal links only when they answer the next unresolved question.

What to prepare

Bring the current tool output and the assumptions you distrust. That may include capacity, TBW, warranty years, daily writes, or for field media, a test file size, record bitrate, reader benchmark, destination roles, checksum method, and hold period. Guides explain tradeoffs; they do not replace current manufacturer documentation, measured workflows, or specialist advice for regulated systems.

What to do next

Use the linked tool to quantify the concept and the reference library to verify units, formulas, or handoff evidence. Comparisons help when two complete approaches remain plausible. Record what changed in the plan after reading. If no input, constraint, or action changed, identify the missing evidence instead of browsing indefinitely.
