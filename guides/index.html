How to use the Guides hub

Where to start

Start with the guide that explains the assumption blocking your decision. Capacity, RAID, backup retention, snapshots, media, replacement, and UPS guides each connect a concept to an available calculator. The SSD endurance guide belongs with media and operational planning: it explains rating units, host writes, WAF, cache behavior, virtual workloads, and counter readings before a drive-class decision is made.

Recommended workflow

Read one concept guide, return to the matching calculator with better evidence, and save the revised result. Capacity normally precedes configuration, configuration precedes backup topology, and recovery requirements precede network and cost. For SSD work, convert the specification, model the workload, and then use observed counters to replace an estimate. Follow internal links only when they answer the next unresolved question.

What to prepare

Bring the current tool output and the assumptions you distrust. For endurance, bring capacity, TBW or PBW, warranty years, daily host writes, layout, existing counter data, and a replacement lead time. Guides explain tradeoffs; they do not replace current vendor documentation, measured workloads, or specialist advice for regulated systems.

What to do next

Use the linked tool to quantify the concept and the reference library to verify units or formulas. Comparisons are useful when two complete approaches remain plausible. Record what changed in your plan after reading. If no input, constraint, or action changed, identify the missing evidence instead of browsing indefinitely.
