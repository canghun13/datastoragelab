Snapshots vs Backups

Use snapshots for fast local rollback and independent backups for recovery after broader loss.

Capability difference

A snapshot preserves an earlier local state; it can be quick to use but may share the same system and failure domain. A backup is a separately recoverable copy.

Combined workflow

Reserve snapshot space for short rollback windows, then create independent copies and test restores. Do not count snapshots as an additional 3-2-1 copy.
